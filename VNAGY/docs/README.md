# VNAGY — Offline‑First Security Doctrine  
Minimal • Deterministic • Explicit

This directory contains the core documentation for the VNAGY security doctrine.  
All documents follow the VNAGY writing standard: offline‑first, modular, behavior‑driven, and strictly deterministic.

## Structure

- **AI Isolation Policy (v1.1)**  
  Defines isolation boundaries, passive isolation rules, and deterministic module interaction.

- **Behavior Engine Specification**  
  Describes signal ingestion, heuristic scoring, CPU‑behavior monitoring, and killing‑chain mapping.

- **VNAGY Rule Format (Enterprise v1.0)**  
  Formal rule structure for behavior detection, scoring, and governance enforcement.

- **Killing Chain Model**  
  VNAGY‑adapted chain with MITRE phase mapping and deterministic escalation logic.
